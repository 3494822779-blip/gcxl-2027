# 上位机 ↔ 下位机串口协议

读者：下位机（单片机）固件开发者。上位机是 Jetson 上的 ROS 2 `actuator` 节点，经 `serial_node` 收发。
代码依据：`ros2_ws/src/block_perception/block_perception/actuator.py`。本文与该文件必须同步修改。

## 1. 物理层

| 项 | 值 |
|---|---|
| 设备 | 上位机默认 `/dev/ttyACM0`（`serial_node.port`） |
| 波特率 | 115200（`serial_node.baud`） |
| 帧格式 | 8N1，无流控 |
| 编码 | ASCII 文本，一帧一行 |
| 行结束 | 上位机发 `\n`。下位机收到 `\r\n` 也要接受，下位机发 `\n` 或 `\r\n` 均可 |

## 2. 帧格式

```
$<类型>,<字段1>,<字段2>,...*<校验>\n
```

- `$` 起始，`*` 之后是校验，校验为 `$` 与 `*` 之间所有字符的逐字节异或，用 2 位大写十六进制表示。
- 校验错、字段个数不对、数值无法解析的帧，直接丢弃，不执行，不回复。
- 数值一律为十进制，小数点为 `.`。

校验例（C）：

```c
uint8_t x = 0;
for (const char *p = body; *p; p++) x ^= (uint8_t)*p;   // body = "$"之后、"*"之前的内容
```

## 3. 上位机 → 下位机：控制帧 `CMD`

固定频率 20 Hz（每 50 ms 一帧），每帧包含全部 5 路控制量。

```
$CMD,<seq>,<lw>,<rw>,<lg>,<rg>,<cp>*<校验>
```

例：`$CMD,42,500.000,500.000,38.4,38.4,-30.0*7C`

| 字段 | 类型 | 单位 | 含义 |
|---|---|---|---|
| `seq` | 整数 0–65535 | | 帧序号，每帧加 1，到 65535 后回 0。用于丢帧诊断，可不处理 |
| `lw` | 小数，3 位 | 下位机轮速原始值 = m/s × 上位机 `wheel_speed_scale`（默认 1000，即 0.5 m/s → 500） | 左轮速度。**正 = 车向前转，负 = 向后转**。量级约 ±500 |
| `rw` | 小数，3 位 | 同上 | 右轮速度，符号约定同上 |
| `lg` | 小数，1 位 | 度 | 左夹爪舵机目标角度，见 §5 |
| `rg` | 小数，1 位 | 度 | 右夹爪舵机目标角度，见 §5 |
| `cp` | 小数，1 位 | 度 | 相机俯仰舵机的**绝对目标角度**。**0 = 初始（回正）位置，正 = 抬头，负 = 低头**。与 `FB` 的 `pitch_deg` 同一坐标系 |

说明：

- 底盘是两轮差速。转向靠 `lw` 与 `rw` 之差：`rw > lw` 车向左转，`lw > rw` 向右转。上位机已经按轮距算好，下位机只需要把轮速原始值换算成电机指令（编码器闭环或开环由下位机决定）。
- `|lw|`、`|rw|` 上位机限幅 `max_wheel_speed × wheel_speed_scale`（默认 0.5 × 1000 = 500）。`cp` 限制在 `[cam_min_deg, cam_max_deg]`（默认 −15° 到 30°）。下位机仍应按自己的硬件上限再限一次幅。
- **相机固定时**（上位机 `camera_servo: false`，目前的默认）：`cp` 始终发固定值 `camera_fixed_deg`（默认 0.0），下位机可以忽略它，也不需要发 `FB`。
- **相机可调时**（`camera_servo: true`）：目标丢失、指令过期、抓取过程中，上位机会发 `lw=rw=0`；`cp` 保持当前目标角度不变。抓取时 `cp` 先变为 `grasp_pitch_deg`（低头看物块，默认 −15°），夹爪合拢完成后回到 0°（回正）。上位机自己把俯仰速度积分成角度，下位机不需要处理速度。

## 4. 下位机 → 上位机：反馈帧 `FB`（仅相机可调时需要）

相机固定时（`camera_servo: false`）下位机不需要发这个帧。相机可调时，下位机上报相机俯仰舵机当前角度，**至少 20 Hz**。上位机的前进补偿和抓取判断都依赖它；超过 0.25 s 没有新反馈，上位机认为反馈过期，不会前进，也不会触发抓取。

```
$FB,<seq>,<pitch_deg>*<校验>
```

例：`$FB,3,-30.5*02`

| 字段 | 类型 | 单位 | 含义 |
|---|---|---|---|
| `seq` | 整数 | | 下位机自己的帧序号，上位机不使用 |
| `pitch_deg` | 小数 | 度 | 相机俯仰角。**0 = 初始（回正）位置，正 = 抬头，负 = 低头** |

要求：

- 角度必须与 `cp` 同一坐标系：下发 `cp` 为某个角度后，`pitch_deg` 应当趋近这个值。舵机转速由下位机自己决定，建议不要太快，避免画面抖动。
- 抓取时上位机会先把相机低头到 `grasp_pitch_deg`（默认 −15°，容差 `grasp_pitch_tol` 0.03 rad ≈ 1.7°），到位后夹爪才合拢；夹完后相机回到 0°（`pitch_home`，容差 `pitch_home_tol`，默认 0.03 rad ≈ 1.7°）。所以"0°"必须是真实的初始位置。
- 抓取触发角由上位机标定（alignment 的 `grasp_pitch` 与 actuator 的 `grasp_pitch_deg` 是同一角度，默认约 −15°），下位机不用处理。

## 5. 夹爪角度规定

这是下位机和上位机共同遵守的约定。

1. `lg`、`rg` 是舵机的**绝对目标角度**，单位度。左右两个爪使用**同一套约定**：**数值越大，爪越向外张开**。
   舵机镜像安装造成的方向相反，由下位机在内部取反处理，上位机不区分。
2. 初始角度（对应爪的合拢位置）为 **0.0°**。对应上位机参数 `claw_init_deg`。
3. **爪只能从初始角度向外张开，不能向内收到初始角度以内。** 可用范围为 **[0.0°, 90.0°]**。90.0° 对应参数 `claw_max_deg`。角度越大，爪越向外张开。
4. 上位机保证发出的 `lg`、`rg` 都在 [0.0, 90.0] 内。下位机仍要自行钳位：低于 0.0 按 0.0 执行，高于 90.0 按 90.0 执行。
5. 上电后、以及收到第一帧有效 `CMD` 之前，两个爪都保持在 0.0°。
6. 寻找和对准目标时，两爪的角度由框的左右边缘宽度决定，范围在 0°–90° 之间变化，`lg` 与 `rg` 相等。
7. 抓取时，两爪从张开位置向中间合拢到 `claw_close_deg`（默认 0.0°，即初始角度），抱住物体。合拢到初始角度之内是不允许的。
8. 抓取结束后爪保持合拢，上位机不会主动松开。
9. 夹持力与堵转保护由下位机负责：爪碰到物体后电流超限或角度到不了目标时，应限流保持，不要持续硬顶舵机。

> 0.0°、90.0° 这两个值写在 `perception.yaml` 的 `gripper` 与 `actuator` 两节（`claw_init_deg`、`claw_max_deg`）。如果机械上要改，三处（上位机两节、下位机固件）必须一起改。

## 6. 超时保护（下位机必须实现）

- 超过 **250 ms** 没有收到有效 `CMD` 帧：`lw=rw=0`，相机舵机保持当前角度不动（不要回到 0°），夹爪保持当前角度不动。
- 再次收到有效 `CMD` 帧后立即恢复执行。
- 上电默认状态：轮速 0，相机舵机在 0°（回正），夹爪 0.0°。

## 7. 速度与角度的限制

| 量 | 上位机保证范围 | 下位机处理 |
|---|---|---|
| `lw`、`rw` | [−500, 500] | 超硬件上限时限幅 |
| `cp` | [−15.0, 30.0] 度 | 超出机械极限时自行钳位，不要顶死 |
| `lg`、`rg` | [0.0, 90.0] 度 | 再钳位一次 |

## 8. 联调步骤

1. 先接上线，不接电机电源：`python3 scripts/serial_check.py --port /dev/ttyACM0 --tx-only`，确认串口能打开和写入。下位机会发 `FB` 时去掉 `--tx-only`，应显示 PASS。
2. 相机可调时：下位机只发 `$FB`，上位机看 `ros2 topic echo /camera/joint_states`，确认俯仰角符号正确（抬头为正）。
3. 用串口助手手动发 `CMD`，依次验证：
   - `$CMD,0,500.000,500.000,0.0,0.0,0.0*54`：两轮同向前进。
   - `$CMD,0,0.000,0.000,60.0,60.0,0.0*54`：两爪向外张开到 60°。
   - `$CMD,0,300.000,500.000,0.0,0.0,0.0*52`：右轮更快，车向左转。
   - `$CMD,0,0.000,0.000,0.0,0.0,-15.0*4D`：相机转到 −15°（相机可调时）。
4. 停止发送，确认 250 ms 后轮停转，夹爪不动。
5. 启动上位机：`ros2 launch block_perception perception.launch.py camera:=true serial:=true`。`serial:=true` 必须加，否则 `serial_node` 不会启动，下位机收不到任何数据。
