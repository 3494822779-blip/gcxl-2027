# C++ 行为迁移记录

行为基准来自 Git HEAD 中的 Python 源码及测试。对照副本用于迁移验证，不作为运行依赖。不要将“编译成功”解释为真机验收通过。

当前已实现：锁定/重绑定、完整常速度 Kalman/Joseph 更新、类别筛选与障碍排序、夹爪连杆计算、轮速限幅、XOR 串口协议、有界发送队列、会话任务记忆。四个感知节点使用实际消息并处理时间戳、任务隔离、失效状态和同帧关联。执行器实现搜索、扫障、开爪锁定、抓取阶段、反馈序号和安全停车；公开 Action 由 task_executor 转交唯一执行器，结果来自执行器。

核心库没有 ROS 头文件，提供独立 CMake/GoogleTest 构建。配置校验在启动时与在线参数回调中运行。

测试包含核心行为、原 Python 滤波数值对照、任务记忆、伪终端发送、ROS 感知节点及 Action 接受/拒绝/忙碌/取消/超时/完成。测试结果以实际 CTest 输出为准。

仍需核对的验收范围：原 pytest 全部条目的对应关系；搜索/扫障/抓取组合场景的完整 ROS 回归；Action 跨进程失联及抢占竞态；故障联动和单实例保护；Jetson 相机、DeepStream 长时间运行、串口断线和真实抓取。硬件测试不能由离线构建或模拟成功代替。

执行状态机目前仍位于 ROS 执行器实现中，后续还需要提取为独立于 ROS 的核心状态机。当前版本不能声称已完全满足原重构方案。

完整旧测试列表见 [Python 行为规格清单](python_behavior_inventory.md)。

## 本轮验证结果

- 7 个包完成构建；更新后的目标完成安装。
- 独立于 ROS 的核心库：25 个 GoogleTest 通过。
- ROS 感知节点：4 个 GoogleTest 通过。
- Action/执行器：7 个 GoogleTest 通过，包含公开 Action 转发、取消、超时、忙碌、安全复位和单次抓取记忆。
- 串口桥：1 个伪终端端到端测试通过；发送队列与部分写入另在核心测试中覆盖。
- DeepStream 元数据缓存 CTest 通过；XML launch 参数解析通过。
- 当前环境没有 `/dev/video0`，未执行相机、真实串口或机械动作验收。

这些结果不等于原 100 个 pytest 函数已全部等价迁移，也不等于真机可部署验收完成。
