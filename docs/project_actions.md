# 机器人动作行为说明

本文件约定机器人选什么目标、如何扫障与抓取、何时停止。修改文档不会自动改变运行行为，代码和配置需要同步、构建后重启。先根据需求修改文档，经过检查git和明确改动方向后确认后再改代码；本次目标型抓取方案已确认实施。

## 一、启动与动作接口

- 普通启动等待人工任务，不自动抓取。自动运行须显式设置 `autonomous:=true target_class:=<类别>`，只执行一次目标型抓取。
- `target_grasp` 必须同时传 `has_target_class: true` 和非负的 `target_class_id`，没有默认类别。
- `approach_grasp`、`first_grasp` 是相同流程的兼容名称，也必须传类别。普通启动和 `first_grasp.launch.py` 都支持；不再限定 class_0。
- 完全停用丢弃：`discard` 和 `discard_after: true` 会被拒绝，旧 `actuator/discard` 话题也不能执行丢弃。

| 动作 | 行为 | 结束状态 |
|---|---|---|
| `target_grasp`（含两个兼容名称） | 指定类别选目标 → 锁定 → 有障碍时单爪扫一次 → 张爪、抓取 | 保持夹持、停车、相机发出回正指令 |
| `align` | 选目标并对准画面位置，不等待抓取角度，不闭爪 | 停车 |
| `grasp` | 原地停车 → 相机到抓取角度 → 合爪并等待 | 保持夹持、停车、相机发出回正指令；不需要类别 |
| `move` | `distance_m` 正数前进、负数后退，速度为 `speed_mps` | 计时结束停车 |
| `turn` | `angle_deg` 正数左转、负数右转，速度表示每侧轮速 | 计时结束停车 |
| `claw` | 左右夹爪同时到 `angle_deg`，等待 0.5 秒 | 底盘停车 |
| `camera` | 相机到 `angle_deg`，等待新鲜有效的到位反馈 | 底盘停车 |
| `stop` | 空闲时停车保持 | 保持夹爪和相机目标角度；执行中须取消任务 |

## 二、目标选择与障碍判断

1. 在指定类别的真实检测框中，优先选下边缘最低者，再按置信度及跟踪编号打破平局。不再使用上方 class_1 排除规则。
2. 正式目标一经锁定，不因其他物块更近而更换，也不切换成障碍物。目标暂时丢失或编号变化时停车等待原编号恢复，超时或取消后结束。
3. 障碍须是真实检测物块，与目标横向有交集，且其下边缘比目标更低。目标上方物块不因此判为障碍。
4. 多个障碍根据物块物体距离（障碍物框的下边缘距离屏幕下边缘的距离越近的则距离车越近）近远进行扫走。
5. 每个任务锁定的目标不限制扫清障碍的次数，扫完如果还有遮挡就继续进行单侧扫走，然后抓原目标。没有目标时上下移动舵机等待。

## 三、单侧扫走

1. 障碍中心偏左用左爪，偏右用右爪，正居中固定用左爪。选中爪内收到 **−30°**，另一爪保持当时角度。
2. 内收后继续接近正式目标。横向交集宽度 / 目标宽度 **严格超过 50%** 时，叠加朝障碍反方向的转向偏置。
3. 初始转向权重 **10%**，若两个框实际有面积重叠则为 **20%**；偏置为权重乘最大扫走角速度 **1 rad/s**。左障碍向右偏转，右障碍向左偏转。
4. 权重按 `w(t)=w₀·exp(−t/τ)` 衰减，初始 `τ=0.33 秒`。累计 **1 秒有效目标控制时间** 后偏置归零，扫走流程完成；感知无效或目标丢失时停车并暂停计时。
5. 扫走阶段不合爪、不丢弃；提前达到抓取位置时停止前进。扫走结束后，若已保存张爪开度则恢复该开度；否则达到张爪角度后按当时正式目标宽度张爪一次。等待开爪到位时间，再检查抓取条件。
6. 动作完成只代表扫走流程执行完，不确认障碍真的移走；不要求障碍落点，也不再重新检查清障结果。

## 四、普通接近与抓取

1. 水平偏差大时先转向，居中后接近；越靠近目标，视觉转向越轻。
2. 框中心位置为画面高度 **50%**，纵向归一化容差 **0.1**（即高度约 45%～55% 的目标带）。张爪不再由目标带触发：相机实际反馈低头达到 **20°**（actuator 的 `claw_open_pitch_deg`，可修改）且有真实目标及有效宽度时，按当时框宽计算并保存开度，只张开一次。之后不因框宽变化、短时丢失或相机角度反复越过阈值而重新调整；扫走期间不覆盖单爪内收。
3. 目标位置合格、真实观测有效，且相机反馈新鲜、低头达到 **40°（允许低 1.7°，即 ≥38.3°）** 时允许抓取；**超过 40°也可以抓取，不设抓取角度上限门槛**；不额外等待稳定时间。张爪指令等待 **0.5 秒**，后续框宽变化不重置等待，也不要求持续刷新开度数据；合爪仍要求当前真实目标及位置、相机反馈合格。
4. 抓取时底盘停车；相机到位后左爪闭合到 **0°**、右爪到 **5°**，等待 **0.5 秒**。原地 `grasp` 从本步骤开始，不选目标、不扫障、不负责接近。
5. 完成后发出相机回正指令，不等待回正反馈；更新记忆，保持夹持并停车，不丢弃。
6. 关闭相机舵机时，按图像位置接近；过近且足够居中时按 **0.1 m/s** 自动倒退，回到目标带即停止倒退。无相机反馈时，进入目标带按宽度张爪一次；原地抓取直接合爪。

长期闭合角度由 actuator 的 `left_claw_close_deg`、`right_claw_close_deg` 配置，临时张爪和扫走不会改写。普通张爪范围仍为 0～90°，扫走及手动夹爪控制下限独立配置为 −30°。下位机须支持有符号的独立左右爪目标角度；仓库不包含下位机固件。

## 五、停止、超时和记忆

- 一次只执行一个动作，执行中任何新动作（包括 stop）均被拒绝；使用 Action 取消命令中断当前任务。
- 目标型抓取默认总超时 **180 秒**，其他动作 **60 秒**，可用 `timeout_sec` 修改。时间到、取消或成功后底盘保持停止，不自动重启。
- Action 反馈显示实际等待阶段：`waiting_for_gripper_angles` 等待有效开度，`waiting_for_opening` 等待下发张爪，`opening` 等待张爪结束，`stale_or_invalid_target` 表示目标失效，`grasp_pitch` 等待相机到位，`claw_close` 才是合爪阶段。临时帧匹配等待不会覆盖同一目标尚未过期的有效开度；张爪前没有有效宽度时不张爪；张爪后保持已保存开度，合爪仍需当前真实目标有效。`waiting_for_open_pitch` 表示等待相机达到张爪角度。
- 取消或超时停止后续步骤，保持当时夹爪和相机目标角度。目标消息过期、真实目标丢失时停止目标型抓取的底盘接近；单独 align 允许短时预测对准。
- 移动、转向和扫走使用计时控制，没有里程计完成确认；合爪也没有夹持传感器确认。
- 记忆分别记录任务、抓取和扫走。扫走记录正式目标、障碍编号、左右侧及完成/中断状态，不计入抓取次数，不声称已物理清障。
- 抓取记录类别、编号、左右闭合角度及结果；重复完成通知不会重复计数。旧丢弃历史字段仅作兼容保留，新任务不产生丢弃记录。
- 记忆仅保存在本次节点运行的内存中，重启清空；参数保存在 YAML 中。

## 六、调用示例

启动：

```bash
BP_DEBUG=actuator,alignment ros2 launch block_perception perception.launch.py serial:=true
```

显式抓取 class_2：

```bash
ros2 action send_goal /robot/execute block_interfaces/action/RobotTask "{operation: target_grasp, has_target_class: true, target_class_id: 2}" --feedback
```

自动执行一次指定类别抓取：

```bash
ros2 launch block_perception perception.launch.py serial:=true autonomous:=true target_class:=2
```

取消与查询：

```bash
ros2 service call /robot/execute/_action/cancel_goal action_msgs/srv/CancelGoal '{}'
ros2 topic echo /robot/memory --once --qos-durability transient_local
ros2 service call /robot/memory/get std_srvs/srv/Trigger '{}'
```

## 七、实现位置

- `nodes.py` / `first_grasp.py`：类别选择、正式目标锁定、障碍几何判断、对准和抓取就绪条件；`first_grasp_task.py` 为兼容可执行入口。
- `sweep.py` / `actuator.py`：扫走计时与指数衰减、单侧内收、视觉张爪、合爪及唯一串口输出。
- `action_api.py` / `RobotTask.action` / `TargetTask.msg`：动作参数验证、显式类别、任务关联、取消和超时。
- `task_memory.py`：任务、扫走及抓取记忆；`perception.yaml`：角度、速度、衰减及等待时间配置。

修改接口后须重建所有依赖包并重启相关节点。参数说明见 [parameters.md](parameters.md)，串口说明见 [serial_protocol.md](serial_protocol.md)。
